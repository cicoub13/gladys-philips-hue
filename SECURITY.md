# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub instead: **Security → Report a vulnerability**
on this repository. You will get an answer within a few days, and a fix will be
released before the details are made public.

## Supported versions

Only the latest release (the `:latest` image) receives security fixes. Update
the integration from Gladys to get them.
